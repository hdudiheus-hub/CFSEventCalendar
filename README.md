# CF Sport Athlete Commerce Platform

This repository contains the initial Next.js landing page prototype for the CF Sport athlete commerce platform.

## Viewing the visual on GitHub

The normal GitHub repository page displays this README file, not the website UI. The actual visual is the Next.js site in `app/page.tsx`.

This repo is configured for GitHub Pages deployment. After GitHub Pages is enabled for this repository, the visual site will publish from the included Pages workflow.

## Project overview

The prototype presents CF Sport as a fighter-powered commerce ecosystem with:

- Branded fighter storefronts.
- Affiliate attribution and coupon-code tracking concepts.
- CRM automation and customer retention flows.
- Fighter, sponsor, and admin dashboard concepts.
- Content approval and shared workspace concepts.
- A phased launch roadmap.

## Main files

- `app/page.tsx` contains the landing page content and sections.
- `app/globals.css` contains the page styling and responsive layout rules.
- `app/layout.tsx` contains the app shell and metadata.
- `.github/workflows/pages.yml` builds and deploys the site to GitHub Pages.
- `next.config.mjs` exports the site as static files for GitHub Pages.
